# 📱 TechNews Today — Portal de Tecnologia

Bem-vindo ao **TechNews Today**, um portal de tecnologia desenvolvido com HTML e CSS para apresentar novidades do mundo tecnológico de forma moderna, organizada e interativa.

## 🚀 Sobre o projeto

O TechNews Today é uma página web que apresenta conteúdos relacionados à tecnologia, com destaque para a Inteligência Artificial, vídeos sobre tecnologia e um formulário de inscrição para uma newsletter.

O projeto foi desenvolvido como atividade prática para aplicar conhecimentos de desenvolvimento web.

## ✨ Funcionalidades

- 📰 Artigo em destaque sobre Inteligência Artificial.
- 📖 Opção para expandir e ler mais sobre a notícia.
- 📺 Área com vídeo incorporado do YouTube.
- 📧 Formulário de inscrição para newsletter.
- 🎯 Seleção de áreas de interesse em tecnologia.
- ✅ Campo para aceitar os termos.
- 🎨 Layout moderno com gradientes e efeitos visuais.
- 📱 Estrutura com CSS Grid e regras de responsividade.

## 🛠️ Tecnologias utilizadas

- **HTML5:** estrutura e organização do conteúdo.
- **CSS3:** estilização, cores, gradientes, animações e responsividade.

## 💻 Como executar o projeto

1. Baixe ou clone este repositório.
2. Abra a pasta do projeto no Visual Studio Code.
3. Verifique se os arquivos HTML e CSS estão na mesma pasta.
4. Abra o arquivo `index.html` no navegador.
5. Explore as seções do portal.

## 🎨 Design

O projeto utiliza um tema escuro com tons de azul, roxo e rosa, criando uma identidade visual moderna relacionada ao universo da tecnologia.

Também utiliza efeitos de gradiente, cartões com bordas arredondadas, transições e adaptação do layout para diferentes tamanhos de tela.

## 📌 Objetivo acadêmico

Praticar a criação de páginas web utilizando HTML5 e CSS3, aplicando elementos semânticos, formulários, conteúdo multimídia, estilização e responsividade.
